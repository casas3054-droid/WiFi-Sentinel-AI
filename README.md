# WiFi Sentinel AI

## Descripción

Prototipo inteligente para la detección de amenazas de ciberseguridad en redes Wi-Fi de acceso público del municipio de La Paz, Bolivia.

Proyecto académico de la materia de Inteligencia Artificial de la Universidad Mayor de San Andrés (UMSA).

## Características

- Simulación interactiva de redes Wi-Fi.
- Generación continua de datos sintéticos.
- Detección y clasificación de indicadores de amenazas.
- Algoritmo genético para optimizar pesos y umbrales.
- Selección, cruzamiento, mutación y sustitución.
- Comparación entre el modelo tradicional y el modelo inteligente.
- Gráficas de evolución genética.
- Interfaz gráfica desarrollada con Tkinter.

## Tecnologías

- Python 3
- Tkinter
- Algoritmos genéticos
- Visual Studio Code
- Git y GitHub

## Estructura del proyecto

| Archivo | Función |
|---|---|
| main.py | Ejecución principal |
| algoritmo_genetico.py | Motor de inteligencia artificial |
| simulacion.py | Generación de datos y análisis de riesgo |
| interfaz.py | Interfaz gráfica y simulación continua |

## Ejecución

Ejecutar desde la terminal:

`py main.py`

Para realizar las pruebas:

`py main.py --test`

No requiere bibliotecas externas, siempre que Python disponga de Tkinter.

## Alcance

El sistema trabaja con datos simulados y tiene fines académicos y preventivos. No captura tráfico real ni ejecuta ataques informáticos.
